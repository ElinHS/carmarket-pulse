# 六品牌行銷主軸與品牌行動

> 來源：carmarket-pulse 儀表板，匯出日 2026-11-18
> THEMES 為各品牌逐月的行銷主軸；ACTIONS 為可對照銷量的具體品牌行動。依設計原則只做時間對齊，不做因果量化。

## 逐月行銷主軸

### NISSAN

- **1月**：低月付門檻訴求＋萬元安全升級（乙式險＋盲點救星），全車系 Display 大版位鋪量
- **2月**：春節縮量守盤，投放 97% 集中 X-Trail 汽油版
- **3月**：Sakura 特仕定價破局（Kicks 59.9萬起），廣告重心轉向單一車款＋影音
- **4月**：特仕延續：X-Trail 免費越級領航＋4萬配件金；媒體投放大幅收縮
- **5月**：品牌話題月（Z 發表會）＋低月付恆定，媒體轉 YouTube 低量維持
- **6月**：全車系安全配備升級（盲區防護）＋競賽月試乘導流（Tomica）
- **7月**：粋．月國產化上市：主打「百萬內標配通風座椅」，投放縮量 63.5% 押 YouTube
- **8月**：粋．月下探 89.9 萬搶量，但召回輿情壓過媒體；投放全年最低（SOV 0.3%）
- **9月**：回到低月付＋丙式險補助的入門訴求；投放回升至 357 萬但全押 X-Trail×中時電子報 97.9%，影音降至 0.3%

### TOYOTA

- **1月**：全線 0 利率＋決策者贈品（投影機），LEXUS NX/RX 撐大盤曝光
- **2月**：貨物稅減徵最高 10 萬＋全車系零利率，春節守盤
- **3月**：新 RAV4 上市防禦：Mobile01 破億次曝光＋汰舊換新 99 萬起
- **4月**：國產主力「電子後視鏡」特仕升級——視野所及，智能升級
- **5月**：多線並進（Yaris Cross／RAV4／Corolla），Mobile01 天量維持
- **6月**：RAV4 PHEV 上市全網包圍，聲量與銷量同步衝頂
- **7月**：「五大豪禮」堆到頂：首贈 6 年延保＋80 萬 0 利率，投放天量 2.48 億
- **8月**：好禮壓 8/12 前收單製造急迫；投放收斂至 RAV4 獨佔 66.1%，體系包辦前四
- **9月**：豪禮檔期結束回到零利率常態；投放 1.74 億霸版 Mobile01 95%，但重心是 LEXUS UX 與中古車而非新車

### HONDA

- **1月**：CR-V「完售壓軸」出清起手：汰舊換新 100.9 萬＋0利率＋5年延保
- **2月**：出清延續＋CR-V 限時越級升等，廣告近乎靜默
- **3月**：出清加碼最高 20 萬折讓，廣告刻意減量讓路新車
- **4月**：改款空窗：UDN 大版位維持品牌存在感
- **5月**：CR-V e:HEV 上市前造勢：Yahoo＋YouTube 影音預熱
- **6月**：「電油先行者」：CR-V e:HEV＋Prelude 雙上市，單月最大投放
- **7月**：「電油先行者」定調全車系 e:HEV，投放 94% 押 CR-V 回歸（Yahoo 64.7%）
- **8月**：投放退場（54 萬）轉打試乘抽 iPhone 17；HR-V e:HEV 超越 CR-V 汽油版
- **9月**：「加值不減價」以配備包換價格堅持；投放暴增 60 倍至 3,394 萬承接 ZR-V 上市，影音佔比六品牌最高

### FORD

- **1月**：Territory 上市蜜月收割：84.9 萬定價＋三創品牌聯展
- **2月**：新春試駕引流（開運錢母），Territory 延續主打
- **3月**：全民挺棒球試乘導流＋Territory 全力押注 Mobile01 單一版位
- **4月**：轉向 YouTube 精準低量，Mustang 預接單話題
- **5月**：產能空窗守聲量：Mobile01 重押不縮手＋88% 保證購回
- **6月**：精品化雙軌：GQ／IG 版位＋線下促銷與 LINE 封閉社群口碑
- **7月**：「天外飛來禮」美國機票造梗，但投放 99.6% 押 Mustang，Territory 缺席
- **8月**：媒體近乎停投（2 萬元），改以零利率、安心購與等車禮守成交條件
- **9月**：「聲歷其境」限量版把配備包產品化；數位連兩月零投放，Territory 靠累計破萬的既有動能

### HYUNDAI

- **1月**：MUFASA 上市蜜月全面鋪版（Mobile01 77%）＋EASY GO 低月付
- **2月**：春節大縮量，版位轉新聞媒體維持基本盤
- **3月**：VENUE 大改款上市爆量（93% 預算）＋世足試乘＋最高補助 20 萬
- **4月**：TUCSON L 接棒主力，自由時報回歸主導版位
- **5月**：TUCSON L＋INSTER 雙線並行，自由時報高密度鋪貨
- **6月**：Tucson L Turbo Hybrid 上市＋FIFA 世足品牌戰，降價 7–10 萬迎戰 Territory
- **7月**：投放大縮至 77 萬（自由時報 93%），改以配備禮＋5 年六大系統保固鋪底
- **8月**：Tucson L 投放暴增（SOV 0.3%→19.1%、Mobile01 95.7%），全月零影音
- **9月**：轉打現金與月付（Tucson L 直折 2 萬）；投放同步收手 -96%，8 月 Mobile01 攻勢完全退場

### MAZDA

- **1月**：「駕趣隨行」7 年保固差異化，精品分眾（CX-5 FB 影音）
- **2月**：春節極簡投放，多車款保固訴求維持
- **3月**：HOMURA 特仕上市：「賽道基因」加配備不加價，話題媒體分眾
- **4月**：CX-60 精品定位影音溝通（Video 85%），7 年保固續行
- **5月**：CX-5 末代大滿配＋60 期 0 利率全額貸，小預算精準收割
- **6月**：CX-5 完售倒數放量收割：Yahoo 運動版位 86%＋全額分期 0 利率
- **7月**：CX-5「絕響臻藏」出清末代＋7 年保固，影音 34.8% 橋接新世代預售
- **8月**：第三代 CX-5 8/18 上市 94.9 萬起，但上市月數位投放幾近於零（2.6 萬）
- **9月**：新世代改打持有成本與延保；投放 2,089 萬卻 91% 壓在 CX-30，該款掛牌反跌至 34 台
